# 💰 Tip Calculator 
<img width="587" height="588" alt="Screenshot 2026-11-21 115150" src="https://github.com/user-attachments/assets/72a3260c-7f0a-4183-a642-50a28f392b59" />


A bill and tip splitting web application built with **Django** as part of my **60-Day Unique Python Projects Challenge**. Users can enter the total bill, tip percentage, and number of people to calculate the total amount and individual share per person.

## 🛠️ Tech Stack Used
* **Python** (Calculation & Validation Logic)
* **Django** (Web Framework, Routing & Template Rendering)
* **HTML5 & CSS3** (User Interface)

## 🎯 Features
* Calculates tip amount, total bill with tip, and per-person split.
* Input validation for invalid numbers or zero/negative values.
* CSRF-protected POST form handling.
* Tested locally on Brave Browser.
